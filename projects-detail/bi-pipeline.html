Overview

Engineered an end-to-end data analytics workflow simulating real-world corporate lifecycle challenges.

Key concepts

  • Relational databases and joins: Data is stored in related tables; joins recombine them on shared keys, and the choice of join type determines which records survive.
  • ETL: Extract, Transform, Load: pulling data from sources, cleaning and reshaping it, and loading it where it can be analysed.
  • Descriptive statistics: Means, medians, spread and counts that summarise data and catch anomalies before visualisation.
  • BI data modelling: Defining the relationships between tables inside Power BI or Tableau so that filters and measures aggregate correctly.

Methodology & process

  1. Built relational database queries in MySQL Workbench, joining multi-layered tables to extract clean datasets.
  2. Processed and transformed messy corporate records in Excel using dynamic Pivot Tables, logical conditions and descriptive statistics.
  3. Modelled data connections across platforms and deployed interactive dashboards in Power BI and Tableau.

Why it matters

Solves a major corporate pain point by bridging technical database backends with visual front-end business strategy.

Most analyst roles span exactly this chain. Being able to own it end to end means fewer hand-offs and fewer places for errors to creep in.
