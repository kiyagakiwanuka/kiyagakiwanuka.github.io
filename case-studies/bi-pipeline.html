Problem

Corporate data often sits in relational databases while decisions are made from dashboards. This project built an end-to-end workflow connecting the two, simulating real corporate lifecycle challenges.

Approach

  • Built relational database queries in MySQL Workbench, joining multi-layered tables to extract clean datasets.
  • Processed and transformed messy corporate records in Excel using dynamic Pivot Tables, logical conditions and descriptive statistics.
  • Modelled data connections across platforms and deployed interactive dashboards in Power BI and Tableau.

Findings

  • A repeatable pipeline from database back-end to front-end business reporting.
  • Keeps conclusions grounded in statistical validity rather than visual bias.
